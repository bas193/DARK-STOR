## 📋 CARA GUNA

### 📦 Tambah Produk
1. Buka halaman Admin → Login
2. Klik **"Tambah Produk"**
3. Isi nama, pilih kategori, masukkan harga & deskripsi
4. Tekan **"Simpan Produk"** — Terus muncul di halaman utama!

### 📂 Tambah Kategori
1. Buka tab **Kategori**
2. Klik **"Tambah Kategori"**
3. Masukkan nama kategori → Simpan
4. Kategori baru akan muncul dalam filter & pilihan produk

### ✏️ Edit / Hapus
- Tekan butang **Edit** atau **Hapus** pada setiap produk/kategori
- Semua perubahan **disimpan automatik** di pelayar awak
